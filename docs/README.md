# docs

Estatus: `documentacion_gobernante`

`docs/` contiene la lectura oficial del repositorio.

## Subárboles

- `architecture/`: gobierno, arquitectura y auditoría estructural
- `migration/`: migración y trazabilidad de reestructuración
- `operations/`: documentación operativa y normas de uso

Si un documento de `experiments/` contradice `docs/`, prevalece `docs/`.
